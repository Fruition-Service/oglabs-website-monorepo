# OG Labs website

oglabs.io is, **today**, a static mirror of the Framer site `oglabs.framer.website`, regenerated by
a GitHub Action and served from Vercel behind a Cloudflare Worker. A **Next.js 16 rebuild** of the
same site lives in `nextjs/` on the `nextjs-rebuild` branch and will replace the mirror; after the
cut-over this repo follows the Senzo / Fruition pattern (OpenNext on Cloudflare Workers).

Full map: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Human onboarding: [README.md](README.md).

**This repository is public.** Never commit secret values, tokens, `.env*` files or private account
ids. Name env vars; do not paste them.

## Which part are you working on?

### The mirror (repo root on `main`)
- **Never hand-edit generated files**: `*.html`, `blogs/`, `services/`, `industries/`, `legal/`,
  `assets/`, `sites/`, `sync-state.json`. The next sync overwrites them. Content changes happen in
  Framer.
- Pipeline code is `export.sh`, `scripts/*.py|sh` and `.github/workflows/framer-sync.yml`.
  Verify any change with `bash scripts/tests/run-tests.sh` (CI runs shellcheck, actionlint and the
  same tests).
- Every push to `main` deploys oglabs.io. The sync bot also pushes to `main`: pull before branching.
- Trigger a sync by hand: `gh workflow run framer-sync.yml -f mode=sync`.

### The rebuild (`nextjs/` on `nextjs-rebuild`)
```bash
cd nextjs && npm install
npm run dev                          # http://localhost:3300
npm run typecheck && npm run lint    # must pass before a change is done
```
- Follow `nextjs/docs/BUILD-BRIEF.md`: 1:1 with the Framer publish of 13 Oct 2026, no redesigns, no
  copy fixes. Source of truth is `oglabs.framer.website`, not oglabs.io.
- CSS Modules (no Tailwind). Colours from the `--token-<id>` variables in `globals.css`; text styles
  from the `.p-<id>` presets in `presets.css`. Framer's breakpoints: 1200 / 810, desktop-first.
- Every section root gets `data-section="<Framer layer name>"` so `qa/compare.mjs` can match it.
  Check parity at 1440, 1000 and 390 wide.
- Blog posts come from HubSpot (`src/lib/hubspot.ts`) merged with repo copies; keep the
  field-mapping rules in that file (title is `name`, author from `blogAuthorId`, never
  `authorName`).

## Gotchas

- **Do not merge `nextjs-rebuild` into `main` before the cut-over plan** (ARCHITECTURE §6). The 36
  reference `.html` files under `nextjs/qa/framer/` would make `export.sh` and `verify-parity.py`
  see orphan routes and every production sync would fail.
- **Never submit a real form**, in tests or by hand: the Solution Finder posts real leads to HubSpot
  and the newsletter posts to Framer. Intercept with Playwright `page.route()`.
- **HTTPS, `orangegrowth.io` redirects and the canonical rewrite live in the Cloudflare Worker in
  front of Vercel, not in `vercel.json`.** A redirect in `vercel.json` cannot see the original
  scheme. The Worker's source is not in git.
- The mirror's canonicals say `https://orangegrowth.io/...` on purpose (`DST` in `export.sh`, pinned
  by a test); the Worker rewrites them. Do not "fix" `DST`.
- Framer throttling returns the homepage with HTTP 200. The canonical-path check in `export.sh` and
  `framer-source-state.sh` is what catches it; keep it.
- The workflow stages with `git add -A -- '*.html'`, not `-u`: `-u` silently dropped every new page.
- GitHub ignores the `*/15` cron for hours at a time. `oglabs-framer-poller` is meant to trigger the
  sync within a minute of a Framer publish, but its `GITHUB_TOKEN` secret is unset.
- `.vercelignore` keeps docs and pipeline files off oglabs.io (the deployment serves the repo root).
  Add new non-site files there too.
- `nextjs/qa/*.mjs` loads Playwright from the Fruition website checkout by absolute path.
